# Final Report Format

Template for the `FINAL_LOGIC_REPORT.md` generated by the Chain & Reporter Agent.

---

## Report Language

Use `output_lang` from `_session.json`:
- `en` → English
- `zh` → 中文
- `ja` → 日本語

All section headers, descriptions, and recommendations must be in the specified language.
Code snippets and technical identifiers (CVE, CWE, VULN-xxx) remain in English.

---

**Root Cause / 根本原因**: {explanation of the fundamental flaw}

**Exploit Conditions / 漏洞利用条件**

Each condition should be detailed with type, requirement status, and default values where applicable:

| Condition | Type | Required | Default | Vulnerable Value | Notes |
|-----------|------|----------|---------|------------------|-------|
| {Condition 1: e.g. "skip_verify enabled"} | config | ✅ Yes | `false` | `true` | Must be explicitly enabled |
| {Condition 2: e.g. "Network access to endpoint"} | network | ✅ Yes | — | — | Direct connectivity required |
| {Condition 3: e.g. "No CAPTCHA protection"} | config | ❌ No | `disabled` | `disabled` | Increases success rate |

**Condition Types:**
- `config`: Configuration setting (MUST include default_value and vulnerable_value)
- `permission`: User role or access level requirement
- `network`: Network accessibility condition
- `environment`: Deployment/infrastructure condition
- `user_action`: Victim interaction required
- `timing`: Time-sensitive condition

## Severity Definitions

| Severity | Icon | Criteria | Fix Timeline |
|----------|------|---------|-------------|
| Critical | 🔴 | Direct account takeover, direct financial loss, mass data breach | 24 hours |
| High | 🟠 | Privilege escalation, significant data exposure, core security bypass | 1 week |
| Medium | 🟡 | Information leakage, limited bypass, conditional exploit | 1 month |
| Low | 🟢 | Best practice violation, minimal impact | Next release |
